# NutriYou
A lightweight UI prototype for a personalized meal recommendation engine featuring Nigerian food staples.
NutriYou is a frontend prototype for a dietary recommendation engine. It captures user preferences to map taste profiles using familiar Nigerian staples. Built with vanilla web tech to showcase product-thinking and clean UI design before integrating backend machine learning algorithms.
